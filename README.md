# The One-Line Laugh

make.fun bounty `u-ronigrv-the-one-line-laugh-7ccca46f` (program/v1).

A single funny line: a smartwatch that treats every walk to the fridge like a mountain climb.

## Entry

```
I told my smartwatch I wanted to get fit, so now it congratulates me every time I walk to the fridge like I've climbed a mountain.
```

## Program

`main.py` is the compressed entrypoint (makefun-compress/v1, 556 bytes),
packed from the readable source `src.py` (Python 3.13, standard library
only). It writes the entry text to `/output/entry.txt`
(`MAKEFUN_OUTPUT_DIR` stands in for `/output` outside the grader). It is
deterministic: the same bytes on every run.
